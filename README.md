# AI 学习伙伴（AI Agent 课程版）— 教学平台落地案例

> **比赛作品公开档案。** 面向学生的课程问答学习伙伴 + 面向讲师的教学洞察看板。本仓库公开技术方案、架构决策与效果数据；源码、课程内容与真实教学数据保留在私有仓库。

## 一句话

把「一门 AI Agent 课程」做成「24 小时在线的 AI 学习伙伴」——从最懂的 AI Agent 课程开始，验证「学什么都陪你到会」。

## 背景与问题

一门硬核工程课（AI Agent）的真实教学痛点：

1. **答疑不及时** — 学生课后有问题，讲师不可能 24 小时在线；资料散落在课件、代码、讲稿里，翻起来慢。
2. **训练无闭环** — 有资料没题目；做了题没人即时批改，练完不知道对错。
3. **进度不可见** — 讲师看不到学生卡在哪个知识点、哪些题大面积做错、项目做到哪一步。

## 方案

一个一体化 MVP，把四件事收敛到同一条链路：

| 模块 | 职责 | 关键能力 |
|------|------|----------|
| **课程问答** | RAG + 引用直达资料 | 有依据回答 / 检索恢复 / 主动拒答 |
| **训练闭环** | 出题 → 作答 → 批改 | 按 Rubric 加权评分，知识点粒度 |
| **项目陪练** | 立项向导 + 个性化清单 | 里程碑逐级推进，勾选持久化 |
| **教学洞察** | 讲师看板 | 掌握度矩阵 / 薄弱点排行 / 里程碑漏斗 |

后端是**领域无关**的学习引擎，课程内容经**课程包**注入，加新课 = 放新目录、引擎零改动。

## 架构概览

```
学习引擎 (Learning Engine)   ← 领域无关、可复用
  陪伴 · 学习者档案 · 训练闭环 · 项目闭环 · 教学洞察
        │ 加载
课程包 (Course Pack)         ← 领域特定、可插拔
  资料/知识库 · 知识点体系(taxonomy) · Rubric · 结课项目
        ▲
  第一个课程包 = AI Agent 课程 (LangChain / LangGraph / MCP / RAG)
```

```
学生提问 → LangGraph 条件路由 → 检索 + 证据分级
              ├─ 证据充分 → 有依据回答（引用直达资料）
              ├─ 证据不足 → 查询改写 + 重检索回环
              └─ 达上限   → 主动拒答（不编造引用）
```

## 核心机制

**① 有依据的问答：条件路由 + 证据分级 + 主动拒答**

基于 LangGraph 构建带条件路由的问答状态图，实现资料来源定位与证据分级机制：先定位答案出自哪份资料、给出证据等级，证据不足时进入查询改写与重检索回环，达到上限后走向拒答分支。系统具备「有证据回答、检索恢复、主动拒答」三条可测试路径，支持按节点定位问题，并通过离线评估验证拒答与引用来源的关联行为。

**② 拒绝无限循环：重生成的确定性终止**

针对模型持续输出缺失引用标记、触发重生成无限循环的技术挑战——且测试替身自带的前缀恰好通过审核检查从而掩盖缺陷——为回答重生成路径增加独立计数与循环上限，并补充「始终输出无引用文本」的回归测试用例，确保异常路径具备明确终止条件，有效控制重复模型调用。

**③ 引擎与课程解耦**

通过统一 `CoursePack` 对象注入知识点、评分标准、题库和里程碑，使课程内容维护与引擎开发完全分离。引擎内零课程硬编码，第一个课程包即覆盖 4 个课程模块、14 个知识点、42 道预置题和 6 个项目里程碑。

**④ 学习者状态模型**

构建区分问答接触、练习成绩和讲师修正三类可信度依据的学习者状态模型，驱动个性化选题、回答深浅调整，以及讲师端掌握度分布、薄弱点排行等教学洞察。

**⑤ 训练与项目闭环的确定性修复**

定位并修复选题重复返回同题的问题：前端记录本轮已展示题目并通过 `exclude_ids` 传递后端排除已见题，实现当前知识点耗尽后的自动轮换策略。将模糊的进度自述改造为立项向导与个性化项目清单，勾选结果持久化至里程碑状态并供看板展示。

## 技术栈

| 层 | 选型 |
|----|------|
| **后端** | Python 3.11 · FastAPI · LangGraph（StateGraph 编排）· SQLModel · ChromaDB |
| **模型 / 向量** | 火山方舟 Ark（LLM `/chat/completions` + doubao 多模态 embedding）|
| **前端** | React 19 · Vite · TypeScript · Tailwind v4 · shadcn/ui · Recharts |
| **鉴权** | 自签 token（bcrypt + stdlib HMAC），角色随 token（学生 `stu_` / 讲师 `tea_`）|
| **部署** | Docker Compose · nginx 同源反代（免 CORS）· 单行 JSON 结构化日志 |
| **质量门禁** | pytest · eval 质量门禁 · 前端 typecheck / lint / build · CI |

## 效果

### 交付范围（首个课程包）

| 维度 | 数量 |
|------|------|
| 课程模块 | 4（LangChain / LangGraph / MCP / RAG） |
| 知识点 | 14 |
| 预置题 | 42 |
| 项目里程碑 | 6 |

### 工程指标（实测）

- 后端分层单测全绿（1 skip = 真实 Ark embedding 冒烟），eval 质量门禁 4/4 cases passed
- 前端 typecheck / lint / build 全绿、零告警
- CI 双 job：后端（pytest + eval）+ 前端（typecheck / lint / 单测 / build），PR 与主干推送自动跑
- 容器化部署：nginx 同源反代 + 命名卷持久化业务库与向量索引，生产密钥 fail-fast 校验
